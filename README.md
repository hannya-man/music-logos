A family of 14 music logos for apps and products, drawn in a woven gold-and-silver line style. Every logo comes in three colour variants, as both SVG and PNG, and all of them are generated by a single Python script.

![All 14 logos in the gold variant, arranged in a grid](preview.png)

<sub>The first cell, `source`, is the original link logo the family is based on. The generator rebuilds it to confirm that the geometry matches. It is not included as a separate asset.</sub>

## Highlights

- **Ready to use:** each logo has a 1024 × 1024 PNG and an SVG of under 1.5 KB.
- **Consistent:** every logo shares the same stroke width, weave gap and colours.
- **Clean on any background:** the gaps in the weave are real geometry rather than masks, so the transparent variants composite correctly.
- **Reproducible:** the script and its centerline definitions are the source of truth for every asset in this repository.
- **Checked on export:** each PNG is tested for its size, background, colour, margins and centring.

## Variants

Each logo's folder contains the same six files:

| Variant | Files | Background | Colour | Best for |
| :------ | :---- | :--------- | :----- | :------- |
| Gold | `<name>-gold.svg`, `<name>-gold.png` | Opaque dark gradient | Gold and silver gradients | App icons and standalone tiles |
| Black | `<name>-black.svg`, `<name>-black.png` | Transparent | Solid `#000000` | Light backgrounds and print |
| White | `<name>-white.svg`, `<name>-white.png` | Transparent | Solid `#FFFFFF` | Dark backgrounds and photos |

## Usage

Clone the repository, or open a logo's folder on GitHub and download the files you need.

```bash
git clone https://github.com/hannya-man/music-logos.git
```

### On a web page

Prefer the SVG, which stays sharp at any size:

```html
<img src="05-sharp/sharp-black.svg" width="64" height="64" alt="Sharp logo">
```

### Matching the viewer's light or dark theme

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="05-sharp/sharp-white.svg">
  <img src="05-sharp/sharp-black.svg" width="64" height="64" alt="Sharp logo">
</picture>
```

### As an app icon

Use `<name>-gold.png` as your master image. It is an opaque 1024 × 1024 square with no alpha channel, and the logo sits at least 150 px from every edge. Scale it down to the sizes your platform requires.

### In another colour

The black and white SVGs set their colour with a `stroke` attribute on each path. Replace every `stroke` value with the colour you want:

```xml
<path stroke="#000" d="..."/>  <!-- change #000 to your colour -->
```

## Design specification

All values are defined at the top of [`generate.py`](generate.py).

### Geometry

| Property | Value | Notes |
| :------- | :---- | :---- |
| Canvas | 1024 × 1024 px | Set in the SVG `viewBox` |
| Stroke width | 52 px | Used by every logo |
| Weave gap | 18 px | Clear space on each side of the strand on top |
| Corner radius | 44 px | Default, measured to the centerline; individual logos may override it |
| Stroke ends | Square-cut | SVG's default butt cap |
| Margin | At least 150 px | Enforced on export |
| Centring | Within 4 px | Enforced on export, as the difference between opposite margins |

### Colour

| Role | Start | End |
| :--- | :---- | :-- |
| Gold strand | `#F5D888` | `#C9A13D` |
| Silver strand | `#DDDAD3` | `#98948D` |

Both strand gradients run diagonally from top left to bottom right, across the area that colour occupies.

The gold variant's background is a radial gradient centred at (512, 470) with a radius of 800 px:

| Offset | 0% | 30% | 60% | 87% | 100% |
| :----- | :- | :-- | :-- | :-- | :--- |
| Colour | `#151822` | `#10131B` | `#0C0E15` | `#07090D` | `#05060A` |

### How the weave works

1. Each logo is defined as a set of centerlines, called strands. Each strand is either gold or silver.
2. The script finds every point where two strands of different colours cross.
3. At each crossing, it splits the strand going under, leaving square-cut ends clear of the strand on top.
4. It centres the result on the canvas and writes each variant.

No masks are involved, so every gap is genuinely empty.

## Regenerating the assets

You only need to do this if you change a logo or add a new one.

### Requirements

- Python 3.8 or later, with [NumPy](https://numpy.org/) and [Pillow](https://python-pillow.org/)
- Microsoft Edge, which renders the PNGs in headless mode

The assets in this repository were generated with Python 3.14, NumPy 2.5, Pillow 12.1 and Edge on Windows 11. Other setups have not been tested.

### Commands

```bash
pip install -r requirements.txt

# Write every SVG and PNG, then rebuild preview.png
python generate.py

# Render only a contact sheet, which is faster when iterating
python generate.py --sheet sheet.png
```

Both commands need the browser. A full export overwrites the existing assets and stops with an error if a logo fails its checks.

### macOS and Linux

The script expects Edge at its default Windows location. On another system, change the `EDGE` constant at the top of [`generate.py`](generate.py) to the path of your Edge, Chrome or Chromium executable. This is expected to work but has not been tested.
